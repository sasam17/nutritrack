# Himalo

Himalo is a calorie tracker that knows dal bhat, momo and the rest of the Nepali plate, and handles food from everywhere else too. This repository hosts the Android APK releases and the brand assets.

Himalo was previously called NutriTrack.

- **Brand assets:** [`branding/`](branding/). Run `python3 branding/generate.py` to rebuild every icon from the vector source.
- **Rebrand checklist** (app code, Firebase, Play Store): [`docs/REBRAND.md`](docs/REBRAND.md)
